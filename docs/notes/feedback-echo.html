echo - zoomed, warped picture echo

A 256x256 8-bit picture (ways.tga) is stretched over the screen through a fixed twist table and scrolled in a small Lissajous-like path; each frame the previous result is shrunk to 80% around the screen centre, blurred with a 2x2 box filter, multiplied by 0.70 and the new picture is added on top (saturating). Because the previous frame is fed back through the zoom, every earlier copy of the picture keeps shrinking and fading: an infinite tunnel of echoes.

Two buffers of 64000 bytes are ping-ponged (the output of one frame is the input of the next, and a copy goes to the screen buffer). The twist table is built once: (x*256/320, y*256/200) displaced by 15*sin(0.0005*(x-160)*(y-100)) in both coordinates and packed as a 16 bit linear index (y<<8)+x, so the picture lookup is one table read and a 16 bit wrap. The picture offset is 6144 + 256*(ceil(32cos T)+ceil(4sin T)) + ceil(32sin T) + ceil(8cos T), T = 0.04 x absolute frame counter (centiseconds).

The inner loop is self-modifying code: before every frame the handler stores the buffer addresses, the table address and the scroll offset into the operand fields of the instructions of the loop (the [reg+1] operands in the listing are placeholders), and the two small lookup tables (the zoom tables for x and y and the attenuation table) are copied into the code segment itself. A classic trick to free registers - the loop needs no base pointers. The tables have one slot too few: x=0 and y=0 read a never-initialised slot (zero), the first row and column therefore sample from (0,0).

Patching the loop (0xb363f)

b3640  mov dword ptr [0xb3633], esi; self-modifying code: the arguments are written into the operands of the loop below
b3646  mov dword ptr [0xb36e1], edi; -> displacement of the store at b36df
b364c  mov dword ptr [0xb36d9], ebx; -> displacement of the picture read at b36d7
b3652  mov dword ptr [0xb36e7], eax; -> displacement of the second store (b36e5)
b3657  mov dword ptr [0xb36c1], edx; -> operand of the warp table read (b36be)
b365d  mov dword ptr [0xb3637], ecx; time offset into the picture

Per pixel loop (0xb3693)

b3693  mov esi, dword ptr [ebp*4 + 0xb2cb3]; x table (copied INTO the code at 0xb2cb3 by 0xb34e3)
b369a  xor ebx, ebx
b369c  add esi, ecx; + row base (y table)
b369e  mov al, byte ptr [esi]; p = source pixel (zoomed position) in the previous echo buffer
b36a0  mov bl, byte ptr [esi + 0x141]; +p[321]
b36a6  add eax, ebx
b36a8  mov bl, byte ptr [esi + 0x140]; +p[320]
b36ae  add eax, ebx
b36b0  mov bl, byte ptr [esi + 1]; +p[1]
b36b3  add eax, ebx
b36b5  shr eax, 2; box average of 2x2 pixels
b36b8  mov al, byte ptr [eax + 0xb28b3]; attenuation table (also copied into the code, 0xb28b3)
b36be  mov ebx, dword ptr [edi + edi + 1]; ebx = warp[i]  (16 bit index into the 256x256 picture)
b36c5  and ebx, 0xffff
b36cb  add ebx, dword ptr [0xb3637]; + time offset
b36d1  and ebx, 0xffff; wrap inside the picture
b36d7  add al, byte ptr [ebx + 1]; add the picture pixel ...
b36dd  jb 0xb36f5; ... saturating
b36df  mov byte ptr [edi + 1], al; write to the output buffer
b36e5  mov byte ptr [edi + 1], al; and to the echo buffer for the next frame
b36eb  inc edi
b36ec  dec ebp
b36ed  jne 0xb3693
