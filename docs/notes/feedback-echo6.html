echo6 - wobbling additive sphere

Same engine as echo4 (see there for the clipper, rasteriser and the additive drawing) but the object is a sphere: an octahedron with vertices at +-300 on the axes, subdivided four times by the integer routine 0x8b218/0x8b060 (every edge midpoint is renormalised to radius 300, 1026 vertices, 2048 triangles). The 8-bit buffer receives the additive, textured (2500 blobs of radius 5, amplitude 12) triangles; there is no smear here - the script follows with lowpass and radialblur instead.

Every frame the sphere is first transformed with an X/Y/Z rotation and the non-uniform scale (2, 0.7, 1), then each vertex is scaled radially by sum of three sines of its own integer coordinates (sin(x/40.84 + P)*0.3 + 2/3 and likewise for y with P*0.8 and z with P*1.3, P advancing with the clock): the wobble. A second small rotation (angles are sines of the clock, about 0.8 rad) and a translation by 1000 units place it in front of the camera. Faces whose triple product with the eye vector is negative are skipped (back-face culling, 0x599f8), the rest is drawn by the shared pipeline with texture coordinates (x,y)*0.0019 of the unwobbled vertex plus the scroll value.

const t1 = Math.sin((x|0)/D + P ) * 0.3 + 2/3;
const t2 = Math.sin((y|0)/D + P2) * 0.3 + 2/3 + t1;
const s  = f32(Math.sin((z|0)/D + P3) * 0.3 + 2/3 + t2);
w[o] *= s; w[o+1] *= s; w[o+2] *= s;
