lowpass - one-pole filter with a one-pixel (four-pixel) bug

The blur is separable: a recursive filter y += (x-y)*a/128 runs forward and then backward along every row, then the same down every column, which gives a symmetric exponential kernel in O(1) per pixel. a = trunc(128*s) where s is the script expression (0.7, 0.85...); at s >= 1 the effect degrades to a copy. MMX processes the four channels of a 32 bit pixel in four 16 bit lanes (psubw / pmullw / psraw 7 / paddw); on 8 bit buffers the vertical pass handles four columns per MMX register, and the horizontal pass uses a 512 entry byte table T[d] = trunc(d*s) built at run time.

The backward pass of the horizontal routines starts one dword (32 bit) or four bytes (8 bit) beyond the end of the scratch row, so the whole image is shifted left by 1 or 4 pixels and the right edge is filtered against zero (the scratch row is shared with the vertical pass, so on 8 bit buffers the right 4 columns even depend on the previous call). We reproduce this, since it is visible as a slow drift in feedback loops.

; 0xb4978  32 bit, one row.  esi=src row, edi=dst row, al=a.  mm6 = a in all four words, mm7 = 0
b4987  mov ebp, 0xfffffb00      ; -1280 = -320 pixels * 4
...
b49a8  movd mm1, [esi+ebp]      ; y[0] = x[0]
b49ac  movd mm0, [esi+ebp]      ; x[i]                    (loop starts here)
b49b0  punpcklbw mm1, mm7       ; y (bytes) -> words
b49b3  punpcklbw mm0, mm7
b49b6  psubw mm0, mm1           ; x - y
b49b9  pmullw mm0, mm6          ; * a
b49bc  psraw mm0, 7             ; / 128 (arithmetic: floors)
b49c0  paddw mm1, mm0           ; y += ...
b49c3  add edi, 4               ; edi = scratch row 0xb3e38
b49c9  add ebp, 4
b49cf  packuswb mm1, mm7
b49d2  movd [edi], mm1          ; scratch[i] = y
b49d5  jne 0xb49ac
...                             ; backward pass: same body, walking down from
b49de  mov esi, 0xb3e38
b49e3  add esi, 0x500           ; <-- should be 0x4fc: reads scratch[320], one pixel too far

// forward: y[0]=x[0]; y[i] = y[i-1] + (((x[i]-y[i-1]) * a) >> 7)
// backward: z = y[319]; for j = 319..0: z += ((TMP[j+1] - z) * a) >> 7; out[j] = z   (TMP[320] == 0)
