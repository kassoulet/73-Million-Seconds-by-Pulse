marchingcubes — polygonising a 16×16×16 field every frame

The cube sequence of the demo (about 106–121 s) is a real-time marching cubes surface. A scalar field of 16×16×16 floats (see metaballs, morphvolume, plasma1volume) is turned into triangles with the iso-level 0.5, and the triangles are poured straight into the mesh of an object of the loaded .exp scene (jabole box02 OurVolume 1 0.5 = scene, object, volume, smooth-shading flag, threshold expression). The polygons keep the material of the first polygon of the original object; only vertices, normals and the triangle list are replaced.

The routine at 0x57c98 is the hand-written, optimised x87 version of a plain C routine that is still in the binary at 0x5800. It scans the 4096 samples once (z, then y, then x). For every sample it looks at the three edges that arrive from the lower neighbours (x−1, y−1, z−1). An edge carries a vertex when exactly one of its ends is ≥ the threshold. The vertex is placed by linear interpolation, and its normal is the interpolated central-difference gradient of the field, normalised with a table-driven 1/sqrt: the exponent is halved with integer arithmetic, the mantissa comes from a 128-byte table built at start-up (0x6258), and one Newton–Raphson step r·0.5·(3−r²·|g|²) finishes it. Vertices live in three arrays of 4096 slots of 0x60 bytes (edges along x, y and z); the static coordinates of a slot are filled once by 0x5fc4, every frame only the coordinate along the edge and the normal are rewritten, so triangles can simply index those slots.

Triangles come from the classic 256-case Lorensen/Bourke table (data segment 0xbda50, edge numbers 0..11 mapped to "array, dx, dy, dz" by 0xbda20 and pre-multiplied by 0x60). The case index is built from two 4-bit masks: the inside flags of the 2×2 samples of the current z plane and the mask of the plane below, which the code remembers in a 4096-entry scratch array (its address is patched into the instructions at run time — self-modifying code). The face normal stored with each polygon is the cross product of two edges. Floats are compared as signed integers (cmp eax, ecx), which is valid for positive IEEE numbers and saves the FPU compare.

Edge test and interpolation (x edge, original 0x57cd4)

57cd4  mov eax, dword [esi + 0x440]      ; v0 = vol[x-1]   (esi = &vol[s] - 0x444, so +0x444 is the sample itself)
57cda  mov ebx, dword [esi + 0x444]      ; v1 = vol[x]
57ce0  cmp eax, ecx                      ; ecx = bit pattern of the threshold
57ce2  jl  0x57cee
57ce4  cmp ebx, ecx                      ; v0 >= thr: need v1 < thr
57ce6  jge 0x57e0f                       ;   both inside -> no vertex
57cec  jmp 0x57cf6
57cee  cmp ebx, ecx                      ; v0 < thr: need v1 >= thr
57cf0  jl  0x57e0f
57cf6  fld dword [esi + 0x444]           ; crossing: t = (v1 - thr) / (v1 - v0)
57cfc  fsub dword [0x100a80]             ;   [0x100a80] = threshold as float (the expression of the event)
57d02  fld dword [esi + 0x444]
57d08  fsub dword [esi + 0x440]
57d0e  fdivp st(1)
57d10  lea ebp, [esi + 0x444]
57d16  push ebp
57d17  lea ebp, [esi + 0x440]
57d1d  mov eax, edx                      ; al = x, ah = y, edx>>16 = z
57d1f  dec al                            ; gradient of sample x-1 ... (call 0x581f2 returns -dV/dx,y,z)

Fast normalisation (original 0x57d63)

57d63  fstp dword [0xc8850]              ; |g|^2 as a float
57d69  mov eax, dword [0xc8850]
57d6e  mov ebp, 0xbe000000
57d73  shr eax, 0x11
57d76  mov edx, dword [0xc8850]
57d7c  and eax, 0x7f                     ; top 7 mantissa bits -> table index
57d7f  and edx, 0x7f800000               ; exponent field
57d85  xor ebx, ebx
57d87  sub ebp, edx                      ; exponent of 1/sqrt = (0xbe000000 - e) / 2
57d89  shr ebp, 1
57d8b  mov bl, byte [eax + 0xc1a58]      ; 8 mantissa bits of 1/sqrt from the 128-byte table
57d91  shl ebx, 0xf
57d94  pop edx
57d95  mov eax, edx
57d97  and ebp, 0x7f800000
57d9d  nop
57d9e  or  ebp, ebx
57da0  mov dword [0xc8858], ebp          ; r ~ 1/sqrt(|g|^2), 8 bits
57db1  fld dword [0xc8858]               ; ... then k = r*0.5*(3 - r*r*|g|^2), normal = g*k

Triangle emission (original 0x580c0 and 0x58110)

580c0  mov eax, dword [esi + 0x404]       ; value at (x, y-1)
580c6  mov ebx, dword [esi + 0x400]       ; value at (x-1, y-1)
580cc  cmp ecx, eax                       ; build the 4-bit mask: bit = (thr < value)
580ce  jge 0x580d2
580d0  inc ebp
...
580e2  mov dword [esi + 0xfca80], ebp     ; remember the mask of this plane (address patched at run time)
580e8  jb  0x581bd                        ; z == 0: nothing below, no triangles
580ee  shl ebp, 4
580f1  mov eax, dword [esi + 0xfca80]     ; mask of the plane below
580f7  or  ebp, eax                       ; case = upper << 4 | lower
580f9  je  0x581bd                        ; 0x00 and 0xff: no triangle
580ff  cmp ebp, 0xff
58105  je  0x581bd
5810b  shl ebp, 6                         ; 64 bytes per case
58110  mov edx, dword [0xc8840]           ; output pointer (0x3c bytes per polygon)
58116  mov eax, 3                         ; polygon has 3 vertices ([edx+0x10])
5811b  mov ebx, dword [ebp + 0xbda54]      ; the three vertex slots of the triangle
58124  mov ecx, dword [ebp + 0xbda58]
5812a  mov eax, dword [ebp + 0xbda50]
58130  add ebx, edi                       ; + address of the cell's lowest corner
58132  add eax, edi
58134  add ecx, edi
58136  fld dword [ebx]                    ; face normal = (b-a) x (c-a)
...
58176  fstp dword [edx + 0x1c]
5817d  fstp dword [edx + 0x18]
