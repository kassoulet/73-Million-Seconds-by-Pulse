plasma1volume and the volume arithmetic

plasma1volume PlasmaVolume 0 1.4 fills a volume with a spherical 3D plasma: v = a + b·sin(r + 0.02·Frame), where r is the distance of the grid point to the centre of the cube (grid coordinates −7.5 … +7.5) and a, b are expressions. The distances are tabulated once (0x18ac2, 4096 floats, the original calls the C sqrt); each frame the x87 code evaluates fsin for only one octant (8×8×8 = 512 sines) and mirrors it in x, y and z with rep movsd, which is exact because the field is symmetric. In the script the plasma is then multiplied into the metaball field (mulvolume OurVolume OurVolume PlasmaVolume) so that the blobs get a travelling ripple.

The other volume effects are tiny 4-floats-per-iteration x87 loops: addvolume, subvolume, mulvolume (dst = A op B), fadevolume dst src f (dst = src·f(Frame); the script uses −1 to invert the field) and morphvolume dst A B t which is dst = A·t + B·(1−t) — note the order, the first source gets the weight t. All write 32-bit floats, so the JavaScript port (Float32Array) reproduces them exactly.

Plasma inner loop (original 0x584b6)

584b4  mov  ch, 8                          ; 8 rows
584b6  fld  dword [edi]                    ; edi walks the distance table
584b8  fadd st(3)                          ; + Frame*0.02
584ba  fsin
584bc  fmul st(2)                          ; * b
584be  fadd st(1)                          ; + a
584c0  fst  dword [eax + edx]              ; (x,   y)      four mirrored stores
584c3  fst  dword [eax + esi]              ; (15-x, y)
584c6  fst  dword [eax + ebx]              ; (x,   15-y)
584c9  fstp dword [eax + ebp]              ; (15-x, 15-y)
584cc  add  edx, 4                         ; x++ ...
584cf  sub  esi, 4                         ; ... mirrored pointers walk backwards
584d2  add  ebx, 4
584d5  sub  ebp, 4
584d8  add  edi, 4
584db  dec  cl
584dd  jne  0x584b6
...
58501  pop  esi                            ; after 8 slices: copy slice k to slice 15-k
58502  mov  edi, esi
58504  add  edi, 0x3c00
5850f  mov  ecx, 0x100
58514  rep  movsd

Morph loop (original 0x5843f)

5843f  fld  dword [edx]                    ; A[i]
58441  fmul st(1)                          ; * t
58443  fld  dword [ebx]                    ; B[i]
58445  fmul st(3)                          ; * (1-t)
58447  fld  dword [edx + 4]                ; four floats are handled per pass,
5844a  fmul st(3)                          ; interleaved to hide the FPU latency
...
58471  faddp st(3)
58475  fstp dword [eax]                    ; dst[i] = A*t + B*(1-t)
58480  add  eax, 0x10
58483  add  edx, 0x10
58486  add  ebx, 0x10
58489  dec  ecx                            ; ecx = 0x1000/4
5848a  jne  0x5843f

JavaScript

v = a + b * Math.sin(PLASMA_TAB[x + 16*y + 256*z] + phase);          // phase = 0.02 * Frame
dst[i] = A[i] * t + B[i] * (1 - t);                                      // morphvolume
