radialblur - in-place zoom feedback on an 8 bit buffer

Every frame each pixel of the 320x200 index buffer is replaced by itself plus a fraction of the picture sampled a little closer to (or farther from) a centre point. Repeated frame after frame this smears bright areas into long streaks that fly towards the centre: the classic "radial blur / zoom feedback" of 1998. There is no second buffer: the sampled pixels come from the very buffer that is being written, and the four quadrants are processed outward from the centre, so a pixel samples neighbours that were already blurred in this very pass and the streaks are propagated across the whole screen in one frame.

The maths is plain 26.6 fixed point. Two tables are rebuilt every frame (one entry per column and per row): xtab[x] = trunc((x-cx)*64*step) and ytab[y] = trunc((y-cy)*64*step*5/6), so the sample position is p + (p-c)*step with a 6 bit sub-pixel fraction. The bilinear interpolation does not multiply at all: a 32 KB table T[f][d] = trunc(d*f/64) (64 fractions x 512 signed differences, built once at 0x70fc) gives a + T[f][b-a] for each of the three lerps. The result is scaled by a 256 byte table att[k] = round(k*strength) and added to the destination with unsigned saturation (add / sbb / or).

Two details of the original that the port keeps: the script command controlfloat writes a global that only radialblur reads - while it is positive it replaces the strength expression and is multiplied by 0.8 on every call, a beat "kick" that decays; and after the four passes a final loop averages the column left of the centre (p[x-1] = (p[x]+p[x-2])/2) to hide the seam. Palettes are applied later by a separate palette effect, the buffer only holds indices.

Seam smoothing (0x70d5)

70d5  xor edx, edx
70d7  xor ebx, ebx
70d9  mov dl, byte ptr [eax]; p[x]
70db  mov bl, byte ptr [eax - 2]; p[x-2]
70de  add edx, ebx
70e0  add eax, 0x140
70e5  sar edx, 1; /2
70e7  mov byte ptr [eax - 0x141], dl; -> p[x-1]   (x = ftol(cx), the seam is smoothed after the 4 passes)
70ed  cmp eax, ecx
70ef  jne 0x70d5

Port (docs/js/fx/feedback.js)

// four passes outward from the centre, then the seam smoothing
pass(cyi, -1, cxi - 1, -1, 0); pass(cyi, -1, cxi, 1, W);
pass(cyi + 1, 1, cxi - 1, -1, 0); pass(cyi + 1, 1, cxi, 1, W);
// per pixel
const va = a + (((c - a) * fy) / 64 | 0);      // table[fy][c-a]  = trunc(d*fy/64)
const vb = b + (((d - b) * fy) / 64 | 0);
const v  = va + (((vb - va) * fx) / 64 | 0);
data[o] = Math.min(255, data[o] + att[v]);      // att[k] = round(k * strength)
script
radialblur name {BUF} {BUF} {cx cy strength step} - four space-free expressions, evaluated every frame with Frame = time since the first run, e.g. {160+150*sin(Frame*0.01) 100+90*cos(Frame*0.01) 0.5+0.3*sin(Frame*0.005) -0.03}
buffers
8 bit 320x200, input = output (in place); the strength expression is overridden by controlfloat while that value is positive
